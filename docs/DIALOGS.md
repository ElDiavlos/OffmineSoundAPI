# Интерфейс OffmineSoundAPI — Dialog API + MiniMessage HEX

Административное меню реализовано на **Paper Native Dialog API** (`io.papermc.paper.dialog.Dialog`). Инвентарь, сундуки и ввод ссылок через сообщения чата не используются.

## Палитра

| Роль | HEX | Тон |
|---|---|---|
| Заголовок и основной светлый текст | `#FFE8D5` | Тёплый крем |
| Строки звуков и действия | `#F4D4B5` | Нежный персик |
| Дополнительные названия и подсказки | `#C7A898` | Светло-коричневый |
| Акцент | `#E3AFAC` | Пыльная роза |
| Успешное действие / прослушивание | `#C7D5B7` | Шалфейный |
| Ошибки | `#E5A7A0` | Мягкий коралл |

Цвета используются в `MiniMessage.deserialize` посредством тегов `<#RRGGBB>`, а переменные подставляются через **`Placeholder.unparsed`**, чтобы ID и имя файла не интерпретировались как MiniMessage-разметка.

## Страницы

1. **Библиотека**: заголовок → количество звуков и текущая страница → **кликабельные строки со звуками** → пояснение → кнопки перелистывания, обновления, добавления и помощи (8 звуков на страницу).
2. **Карточка звука**: прослушивание, копирование вариантов `play`, `playAll`, `playAt` и импорта `SoundApi`, возврат.
3. **Добавление звука**: поля `sound_id` и `sound_url`, кнопка «Скачать», возврат.
4. **Справка**: форматы, GitHub/Dropbox/локальная загрузка, ошибки URL, команды и регулятор громкости Simple Voice Chat.

Сервер обрабатывает **только свои кнопки** с namespace `offminesoundapi`, дополнительно перепроверяя право `osv.admin`. Поля ID и URL валидируются на сервере, а загрузка работает асинхронно.

## Известное ограничение

Клиент Minecraft сам определяет подложку, размеры и стиль рамки ванильного диалога. MiniMessage меняет **цвет и стиль текста**, но не перерисовывает фон или форму кнопок без ресурс-пака и клиентского мода.

API: https://docs.papermc.io/paper/dev/dialogs/

## Расположение списка в версии 2.3.1

Minecraft/Paper размещает настоящие `ActionButton` **после** элементов `DialogBody`, поэтому изменить порядок обычных кнопок внутри диалога нельзя. Для нужного порядка звуки отображаются как **кликабельные строки `DialogBody.plainMessage`**, а не обычные кнопки.

Текст каждой строки оформляется MiniMessage HEX и отправляет собственное событие `ClickEvent.custom(Key.key("offminesoundapi", "sound/<id>"), BinaryTagHolder.binaryTagHolder("{}"))`. Нажатие обрабатывает существующий `PlayerCustomClickEvent`: открывается карточка выбранного звука. Благодаря custom-событию не нужно показывать скрытые административные команды игроку и не возникает диалог подтверждения запуска команды. Проверка `osv.admin` при клике остаётся обязательной.

При пустой библиотеке вместо списка появляется «♫ Библиотека пока пуста». Палитра, заголовки, управление страницами и карточка звука не меняются.
