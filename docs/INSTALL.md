# OffmineSoundAPI 2.3.1 — установка и работа с диалогами

## Установка

1. Подготовьте **Paper 26.3**, **JDK 25**, **Simple Voice Chat для Paper 26.3**. Клиентам для прослушивания нужен мод Simple Voice Chat; обычно требуется доступность UDP-порта 24454 (смотрите конфигурацию Voice Chat).
2. Соберите проект из исходников на JDK 25: `./gradlew clean build` или `gradlew.bat clean build`.
3. Скопируйте `build/libs/OffmineSoundAPI-2.3.1.jar` в папку `plugins/` и **уберите старый JAR** OffmineSoundAPI/OffmineSimpleVoiceElTeam.
4. При использовании MP3, OGG, FLAC, AAC, M4A, OPUS установите FFmpeg, настройте `converter.executable` в `plugins/OffmineSoundAPI/config.yml`.
5. Перезагрузите **сервер**, а не только сам плагин.

Сами файлы лежат в `plugins/OffmineSoundAPI/sounds/`, таблица `ID → файл` — `plugins/OffmineSoundAPI/sounds.yml`. Старую папку с библиотекой предварительно сохраните.

## Административный диалог

Команда: **`/soundadmin`** или `/osv admin` (право `osv.admin`, по умолчанию OP).

1. Открывается **нативный диалог Minecraft** с перечнем звуков и кнопками страниц.
2. Выберите звук — появится карточка, в которой можно нажать «♫ Прослушать», «⧉ Игроку», «⧉ Всем», «⧉ В точке», «⧉ Импорт».
3. Нажатие на кнопку ⧉ копирует соответствующий Java-код **сразу в буфер обмена клиента**, без чата.
4. Нажмите «＋ Загрузить звук» — отдельная форма диалога с полем ID (можно оставить пустым для автогенерации из имени файла) и полем URL.
5. После отправки формы плагин скачает аудио **асинхронно**. При успехе откроется карточка нового звука. При ошибке придёт объяснение в чат, откуда можно вернуться в диалог.

**В чат больше не нужно писать URL**. Для автоматизации и консоли по-прежнему есть `/osv download <id> <URL>`.

## Загрузка аудиофайлов: Catbox не требуется

Плагин **не загружает файлы на Catbox**, а скачивает их на сервер по доступному серверу URL. Если Catbox отдаёт 403/404, обхода запрета нет. Используйте другой источник:

**Способ A — GitHub (удобно для небольших звуков):**
1. Создайте публичный репозиторий (например, `server-audio`). Добавьте туда `alarm.mp3`.
2. Скопируйте URL файла вида `https://github.com/USER/server-audio/blob/main/alarm.mp3`.
3. Вставьте его в форму `/soundadmin`: загрузчик преобразует адрес в прямую ссылку `https://raw.githubusercontent.com/USER/server-audio/main/alarm.mp3`.
4. Файл должен быть реально доступен публично (не только залогиненному владельцу репозитория).

**Способ B — Dropbox (публичная ссылка):**
1. Загрузите файл в Dropbox, создайте ссылку с доступом **всем по ссылке** и разрешённым скачиванием.
2. Вставьте ссылку из Dropbox — загрузчик добавит или заменит параметр `dl=1` и обработает редиректы.
3. Если Dropbox ограничивает скачивание, используйте A или C.

**Способ C — без сайтов и URL (самый надёжный):**
1. Откройте файловый менеджер хостинга или SFTP.
2. Поместите `alarm.wav` или `alarm.mp3` в `plugins/OffmineSoundAPI/sounds/`.
3. Выполните `/osv reload` **от администратора или в консоли** (или перезапустите сервер).
4. Готово: в библиотеке появится ID `alarm`, и API сможет воспроизводить его через `SoundApi.get().play(player, "alarm")`.

**Ограничения:** приватные ссылки, localhost и частные IP запрещены. HTTP(S)-ответ должен содержать настоящие байты поддерживаемого аудиоформата. Сайт может блокировать загрузку с серверов, даже если ссылка открывается в вашем браузере. Длина загружаемого аудио ограничена `audio.max_duration_seconds`, размер HTTP-файла — `download.max_size_mb`.

| Ошибка | Решение |
|---|---|
| `HTTP 404` | Файл удалён или URL неверный; загрузите заново на другой хостинг. |
| `HTTP 403` | Провайдер не разрешает скачивать этот файл с сервера; другой публичный источник или способ C. |
| `HTTP 401` | Требуется авторизация — нужен публичный адрес. |
| `HTTP 429` | Достигнут лимит запросов; дождитесь снятия ограничения. |
| `Content-Type: text/html` | Вернулась веб-страница вместо аудио. Для GitHub используйте ссылку на файл в репозитории; для Dropbox — открытую ссылку. |
| `Нераспознанные данные` | URL отдаёт не MP3/WAV/OGG/FLAC/AAC/M4A/OPUS или файл повреждён. |
| Звук загружен, но не воспроизводится | Проверить Simple Voice Chat на клиенте и сервере, UDP-подключение, а для сжатого аудио — FFmpeg. |

## Настройка громкости Simple Voice Chat

**Каждый игрок отдельно** открывает интерфейс Simple Voice Chat (обычно клавиша **V**), затем **Регулировка громкости / Adjust Volumes** и находит категорию **«Звуки сервера»**. Она управляет громкостью звуков OffmineSoundAPI: персональных (`play`), для всех (`playAll`), пространственных (`playAt`) и маяков. Громкость сохраняется на стороне клиента мода. Если выбрать 0%, эти звуки будут неслышны этому игроку, не затрагивая других игроков. Общий регулятор громкости Voice Chat тоже может влиять на итоговую громкость.

Категория регистрируется под постоянным ID `osv`. В Minecraft-микшере обычных звуков её нет: настройка находится **в Simple Voice Chat**, а не в «Музыка и звуки» Minecraft. Клиенту необходим мод и рабочее подключение к серверному Voice Chat.

## Скрытие административных команд

`/osv` и `/soundadmin`, в том числе варианты с namespace, не показываются обычным игрокам в подсказках команд Minecraft. Используется `PlayerCommandSendEvent`, а при выполнении команда дополнительно проверяет право `osv.admin` (по умолчанию только OP). Это **не отключает публичный Java API** для других плагинов.

Если после изменения прав команды не появились администратору, обновите список команд клиента (переподключитесь или используйте `Player#updateCommands()` в системе выдачи прав).

## Поддерживаемые форматы

`.wav`, `.mp3`, `.ogg`, `.flac`, `.aac`, `.m4a`, `.opus`. MP3/OGG/FLAC/AAC/M4A/OPUS обычно требуют FFmpeg. `audio.max_duration_seconds: 300` ограничивает декодируемое аудио пятью минутами, `download.max_size_mb: 20` — скачивание двадцатью мегабайтами (настраивается в `config.yml`).

## Команды

```text
/soundadmin                          — открыть нативную панель
/osv admin                           — то же
/osv help                            — справка
/osv sounds                          — ID сохранённых звуков
/osv code <id>                       — резервные кнопки копирования в чат
/osv download <id> <URL>             — скачать файл без диалоговой формы
/osv reload                          — перечитать библиотеку
/osv play <ник> <id> [loop]          — одному игроку
/osv playall <id> [loop]             — всем
/osv at <x> <y> <z> <radius> <id>    — временный позиционный звук
/osv stopat <UUID>                   — остановить позиционный звук
/osv place <x> <y> <z> <radius> <beacon> <id> [loop]
/osv queueadd <beacon> <id>          — добавить в очередь маяка
/osv list                            — список маяков
/osv stop <beacon|all>               — остановить маяк(и)
/osv stopplayer <ник|all>            — остановить персональные звуки
/osv stopglobal                      — остановить глобальное воспроизведение
```

### Сборка и проблемы

Для Gradle нужен интернет, реальные зависимости и **JDK 25**; в `build.gradle` указаны `paper-api:26.3.build.+` и `voicechat-api:2.6.24`. `api-version` в `plugin.yml` — `26.3`. Если клиенту не отображаются диалоги, убедитесь, что запущена именно актуальная серверная версия Minecraft с поддержкой диалогов и установлен новый JAR.

См. `docs/API.md` для Java API и `docs/DIALOGS.md` для компонентов интерфейса.
