# Громкость OffmineSoundAPI в Simple Voice Chat (2.3.3)

Звуки управляются клиентским регулятором категории **Server Sounds** (`osv`) в меню **Simple Voice Chat → V → Adjust Volumes**. В Simple Voice Chat 2.6.24 название ограничено 16 **байтами UTF-8**, поэтому вместо длинного русского названия используется `Server Sounds` (13 байт). Она не использует обычные игровые настройки громкости Minecraft и не должна смешиваться с `Other`.

## Как проверить

1. Убедитесь, что Simple Voice Chat установлен **на сервере** и **на клиенте**, что голосовой чат подключён (нет значка отключения).
2. Замените JAR плагина на сборку **2.3.3** и **полностью перезапустите сервер**. Простая команда `/reload` может не восстановить события API Simple Voice Chat.
3. В консоли найдите `Категория громкости Simple Voice Chat зарегистрирована: osv`. Если вместо этого ошибка, скопируйте её из лога.
4. С админ-правами в игре выполните `/osv voicecheck`. В норме будет `Simple Voice Chat: подключён`, `Громкость: Server Sounds (id=osv) зарегистрирована`, `Voice Chat соединение игрока: есть`.
5. Переподключитесь к серверу, откройте `V → Adjust Volumes`, при необходимости проверьте экран **во время воспроизведения звука** (`/osv play <ваш_ник> <id>`).
6. `Other: Amplification 0%` на скриншоте относится к другой категории. Это не подтверждает, что категория `osv` действительно зарегистрировалась; для диагностики нужна команда из шага 4.

Если команда подтверждает регистрацию, а клиентский регулятор по-прежнему не отображается, пришлите `/osv voicecheck`, строку о категории из лога сервера и точные версии серверного и клиентского Simple Voice Chat: серверное API может зарегистрировать категорию, но мы не можем дистанционно подтвердить её отображение на конкретном клиенте.

## Для разработчиков

Плагин вызывает `VoicechatServerApi.registerVolumeCategory(...)` для `osv`, проверяет `getVolumeCategories()`, а при создании **каждого** StaticAudioChannel и LocationalAudioChannel вызывает `setCategory("osv")`. Это обеспечивает единую клиентскую громкость для персональных, глобальных, позиционных и постоянных звуков.

Документация SVC: https://modrepo.de/minecraft/voicechat/api/examples

## Почему появлялась ошибка `String too big`

Версия 2.3.2 передавала имя `Звуки сервера` — 25 байт в UTF-8, тогда как сетевой пакет Simple Voice Chat 2.6.24 разрешает 16. Это приводило к ошибке Netty при отправке категории клиенту и ползунок не отображался. В 2.3.3 передаётся `Server Sounds` (13 байт). ID `osv` не изменился, поэтому ранее сохранённая категория громкости не должна потерять настройку.

Проверка после обновления: **полный перезапуск сервера**, переподключение к нему, `/osv voicecheck`, затем `V → Adjust Volumes → Server Sounds`. Не используйте `/reload` как замену перезапуску.
