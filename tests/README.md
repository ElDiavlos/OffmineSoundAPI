# OfflineChecks.java

Простой набор проверок без HTTP-запросов: конвертация GitHub/Dropbox URL, сигнатуры аудио и фильтрация команд. Предназначен для разработчиков при локальной компиляции с доступными зависимостями Paper/VoiceChat. Проверки **не** заменяют запуск на сервере Paper 26.3 и тестирование реальной загрузки с GitHub/Dropbox.


`DialogLayoutChecks.java` — дополнительная офлайн-проверка порядка элементов в исходнике (счётчик → звуки → пояснение → футер), **не** является клиентским UI-тестом. Запуск из корня проекта: `javac tests/DialogLayoutChecks.java && java -cp tests DialogLayoutChecks`.


`VolumeCategoryChecks.java` — проверка регистрации категории `osv`, защиты от повторной регистрации, восстановления после удаления и сброса состояния. Запускается при офлайн-компиляции со вспомогательными заглушками SVC (не является проверкой настоящего мода/клиента).

`VolumeCategoryPacketChecks.java` — тест регрессии для ошибки Simple Voice Chat 2.6.24 `String too big (was 25 bytes encoded, max 16)`. Проверяет количество байт UTF-8 в названии и описании категории `osv`, её регистрацию, отсутствие повторной регистрации и замену категории со старым названием. Требует API-заглушек или библиотек Simple Voice Chat и Paper на compile classpath; не заменяет запуск на настоящем сервере.
