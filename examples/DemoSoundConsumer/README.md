# Пример вызова API

Это минимальная структура потребителя API. Перенесите `src/` в Java/Gradle проект с Paper API 26.3 и добавьте `compileOnly files('libs/OffmineSoundAPI-2.2.0.jar')`.

Установите оба плагина на сервер. Администратор должен добавить звук `alarm` через `/soundadmin` или `/osv download alarm <URL>`. Команда `/testalarm` проигрывает его исполнителю.

Разработчик должен собирать проект с **Java 25** и реальными зависимостями Paper 26.3. Полная информация: `../../docs/API.md`.
